# Root critical old-anchor signed-return or blocker theorem

**Date:** 2026-08-14

**Status:** cap-free elimination of the critical old-anchor packet whenever
the exact signed missing-base return is admitted; every survivor has a named
floor, retirement, anchor, or release blocker

## Exact localized input

Use an exact root-held `T_{L,times}^*` state after the corrected
critical-localization theorem. Let `r` be the first-priority root,
`x=v_r(X_r)`, and let its current target `Z_r` contain the permanent old
root anchor

\[
 A=T_q+f\subseteq G\setminus X_r,
 \qquad v_r(A)>x.                                \tag{1}
\]

The named nonempty retired packet satisfies

\[
 K\subseteq C_r(Z_r)\subseteq C_r(A)\subseteq A.\tag{2}
\]

Write the full signed root support as

\[
 S^+=Z_r\setminus X_r,
 \qquad S^-=X_r\setminus Z_r,
 \qquad v_r(S^+)-v_r(S^-)=\delta>0.             \tag{3}
\]

Since `A` is disjoint from `X_r`, (1)--(2) give the decisive support fact

\[
 \varnothing\ne K\subseteq A\subseteq S^+.     \tag{4}
\]

## Admitted signed-return branch

Suppose `S^-` is a currently compatible, supplier-closed exterior mode for
the clean release of `K`. Use `T=K` and `R=S^-` in the root-strict clean
subpacket-release theorem.

If `K` is a proper subset of `S^+`, the post-release root margin is exactly

\[
 \begin{aligned}
 v_r(Z_r-K+S^-)-x
 &=\delta-v_r(K)+v_r(S^-)\\
 &=v_r(S^+)-v_r(K)\\
 &=v_r(S^+\setminus K)>0.                       \tag{5}
 \end{aligned}
\]

Thus the clean release is strict. It gives `K` alone to the named later
sacrifice row, releases that row's displaced target, and uses every current
holder of `S^-` as an explicit supplier. If the candidate is EFX, it
contradicts global lexicographic maximality. Otherwise the clean-release
response theorem gives proper or empty `K`-intersection: the root target is
disjoint from `K`, while a wall against the target `K` has a desired
one-good deletion and hence a globally minimum response properly contained
in `K`. This is strict packet or hitting progress.

If `K=S^+`, (3) is the unique root-equality base restoration. The admitted
equality packet-spread theorem leaves one incoming good at the root when
`|K|>=2`, or uses an off-packet donation when `K` is a singleton. In both
cases the root becomes strict and every response has proper or empty
intersection with `K`. Hence the equality branch also closes.

Therefore

> no exact critical old-anchor recurrence can retain an admitted signed
> missing-base return.

This conclusion uses neither an all-donor global supplier star nor a
historical-source reversal.

## Exact surviving blocker

At a recurrent critical old-anchor packet, `S^-` must fail at least one
premise of the clean signed-return mode. Preserve the first failed premise
from the actual normalization audit. By the full signed-transfer contract it
has one of the following physical types:

1. **retired-support blocker:** a good of `S^-` is tied to another current
   retired packet or collision whose normalization must be executed first;
2. **anchor/core blocker:** moving a good of `S^-` would change a protected
   physical anchor or retained core, so the move is already a named
   root/anchor-exchange obligation;
3. **typed-floor blocker:** a nonsacrificed owner would fall below a
   protected, nonwaivable current floor;
4. **supplier/release blocker:** the required current holder, residual
   destination, or release edge does not close under the originating
   operation.

If the blocker or its adopted response/anchor coordinate is new, the finite
signed record strictly progresses. If an anchor/core blocker is executed,
it is the contracted root/anchor outcome. Thus a failure of every permitted
outcome leaves only an **exact repeated blocker** of types 1, 3, or 4 at the
same physical anchor and signed state. Merely naming that blocker is not
progress.

## Typed collision consequences

- **Strict capture:** recipient surplus does not pay the root; the admitted
  signed return closes independently of that surplus, and otherwise the
  first exact return blocker is retained.
- **Equality-critical payment:** root equality occurs only when `K=S^+` and
  is eliminated by the admitted equality-spread operation. Recipient
  equality is not promoted to root payment.
- **Base-floor debt:** only the designated later sacrifice row's auxiliary
  floor is waived. A different protected floor appears explicitly as blocker
  type 3.
- **Release compatibility:** every good of `S^-` keeps its current supplier;
  failure of the supplier set to close is blocker type 4, not an inferred PI
  cycle.
