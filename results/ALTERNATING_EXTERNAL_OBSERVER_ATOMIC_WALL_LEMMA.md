# Alternating external-observer atomic wall lemma

**Date:** 2026-08-09
**Status:** analytic proof of the four-rival atomic certificate
**Scope:** the seven-good alternating atom and priority order `(p,s,r,q)`

## Setup

Write the base allocation as

\[
X_p=\{x\},\quad X_r=\{t_r,b_r\},\quad
X_s=\{y\},\quad X_q=\{t_q,b_q\},
\]

with `f` unallocated.  Assume the complete strict alternating structural
cell used in the global-lex audit.  In particular, `r` envies `y`, `q`
envies `x`, `T_q\cup\{f\}` is a desired set for `s`, and the compatible
family from `q` into `X_r` with incoming good `b_q` is absent.

Keep `p` anchored at `x`.  Consider the four allocations

\[
\begin{array}{c|cccc}
 &p&r&s&q\\ \hline
R_1&x&t_r b_r b_q&y&t_q\\
R_2&x&y&t_q f&t_r b_r b_q\\
R_3&x&y&t_q f&b_r b_q\\
R_4&x&t_r b_q&y&t_q.
\end{array}
\]

Unlisted goods are charity.

## Exact theorem

> At least one of `R1`--`R4` is EFX and lexicographically improves the base
> in priority order `(p,s,r,q)`.

## Failure-wall reduction

Base EFX, desired-set safety, and the alternating inequalities make every
comparison safe except the following walls.  A label `Rk:i!>j-g` means that
in `Rk`, observer `i` strongly envies `j` after deletion of `g`.

\[
\begin{array}{c|l}
R_1&q!>r-t_r,\ q!>r-b_r,\ q!>r-b_q\\
R_2&r!>q-b_r,\ q!>s-f\\
R_3&q!>s-f\\
R_4&q!>r-t_r,\ \text{or }R_4\text{ fails to improve }r.
\end{array}
\]

The exact audit independently checks that this list is complete.  Blocking
all four rivals would require one wall from every row.  Every such selection
contains one of six impossible pairs:

1. `R1:q!>r-bq` and `R2:q!>s-f`;
2. `R1:q!>r-br` and `R2:q!>s-f`;
3. `R1:q!>r-tr` and `R3:q!>s-f`;
4. `R3:q!>s-f` and `R4:q!>r-tr`;
5. `R2:r!>q-br` and failure of `R4` to improve `r`;
6. `R1:q!>r-bq` and failure of `R4` to improve `r`.

Pairs 1--4 are immediate strict cycles in `q`'s row.  For example, pair 3
asserts

\[
v_q(t_q)<v_q(b_r+b_q)<v_q(t_q).
\]

For pair 5, failure of `R4` to improve `r` says

\[
v_r(b_q)\le v_r(b_r).
\]

But `r` envies `y`, so

\[
v_r(y)>v_r(t_r+b_r)\ge v_r(t_r+b_q),
\]

contradicting `R2:r!>q-br`.

For pair 6, `R1:q!>r-bq` gives

\[
v_q(t_q)<v_q(t_r+b_r).
\]

Consequently `q` envies the augmented offer
`X_r\cup\{b_q\}` because

\[
v_q(X_r+b_q)>v_q(t_q+b_q)=v_q(X_q).
\]

Set `W=X_r\cup\{b_q\}`.  The first inequality in pair 6 makes `q` envy
`W`, because

\[
v_q(W)=v_q(X_r)+v_q(b_q)>v_q(t_q)+v_q(b_q)=v_q(X_q).
\tag{1}
\]

If `W` is deletion-safe for every observer, it is itself a desired set for
`q`, contradicting absence of the `q`-into-`X_r` compatible family.  The
remainder after deleting `b_q` is `X_r`, which is safe for every observer by
the exact envy graph.  Hence a failure of deletion safety must concern one
of the mixed pairs

\[
\{t_r,b_q\},\qquad \{b_r,b_q\}.
\tag{2}
\]

Every singleton among `t_r,b_r,b_q` is safe for every observer by base EFX.
Therefore, if an observer strongly envies either pair in (2), that pair is
a desired set for that observer.

For observers `p` and `q`, either pair belongs to the forbidden family into
`X_r` with incoming `b_q`.  It remains to consider `r` and `s`.  Failure of
`R4` to improve `r` gives

\[
v_r(b_q)\le v_r(b_r),
\]

and hence `v_r(t_r+b_q)\le v_r(X_r)`.  Agent `r` cannot strongly envy the
first pair.

For `s`, desired-set safety of `\{t_r,f\}` for `p`, together with the fact
that the same set is not desired by `s`, gives

\[
v_s(t_r+f)\le v_s(y).
\tag{3}

On the other hand, `s` desires `\{t_q,f\}` and does not envy `X_q`, so

\[
v_s(t_q+f)>v_s(y)>v_s(t_q+b_q),
\]

which implies `v_s(f)>v_s(b_q)`.  Combining this with (3) yields

\[
v_s(t_r+b_q)<v_s(t_r+f)\le v_s(y).
\]

Thus `s` cannot strongly envy the first pair either.  Any unsafe observer
among `r,s` must therefore strongly envy `\{b_r,b_q\}`, producing a
forbidden `r`- or `s`-into-`X_q` compatible family with incoming `b_r`.
Every possible deletion-safety failure contradicts one of the four absent
families.  Pair 6 is impossible.

Thus the four rivals cannot all be blocked.  Each has `p` fixed.  `R2` and
`R3` improve `s`; `R1` improves `r` while preserving `s`; and `R4` is used
only on the branch where it improves `r`.  Hence any unblocked rival is the
required rooted lexicographic escape. \(\square\)
