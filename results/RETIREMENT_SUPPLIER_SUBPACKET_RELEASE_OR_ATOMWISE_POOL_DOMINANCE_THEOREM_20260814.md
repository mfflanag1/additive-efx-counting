## Controlled return of an arbitrary subpacket

Let the protected root hold

\[
 Z_r=K\mathbin{\dot\cup}H,
 \qquad v_r(Z_r)=x+\delta,
 \qquad \delta>0,                                \tag{1}
\]

and let `u` be the named retirement supplier/historical recipient of `K`.
Assume the complete originating transition separately admits returning the
chosen nonempty `T subseteq K` to `u`, together with a supplier-closed
compatible `K`-free exterior packet `R`. Return `T` to `u`, give `R` to the root, and let the root retain
`(K-T)+H`. Exterior donors may be sacrificed when the root remains strict.

The exact root margin is

\[
 v_r((K-T)+H+R)-x
   =\delta-v_r(T)+v_r(R).                        \tag{2}
\]

Thus the controlled return is strict whenever

\[
 v_r(R)>v_r(T)-\delta.                           \tag{3}
\]

## Why a successful proper return cannot repeat the same packet

If `T` is proper, the retired packet is physically split between the root
target `(K-T)+H+R` and the nonroot return target containing `T`. Every
single-target response then intersects `K` in a proper subset. Hence a strict
candidate gives EFX, root/response routing, or immediate proper-packet
reduction; the same whole `K` cannot be reconstructed in one response.

For `T=K`, the complete-packet supplier-release theorem applies. A whole hit
on the nonroot return target enters the finite safe-envelope descent. Other
retired support in `R` is normalized before execution.

Consequently every `T` satisfying (3) is eliminated from an exact recurrent
root packet.

## Conditional proper equality return

Suppose `T subsetneq K` and

\[
 v_r(T)=\delta.                                  \tag{3e}
\]

Take `R=empty`. The root returns exactly to its base value, the named return
owner receives `T` while keeping its old bundle and therefore strictly
improves, and every other owner is unchanged. An EFX endpoint is
lexicographically above the base. If the candidate is not EFX, the root
target contains only `K-T` and the return target contains only `T`; every
single-target response meets a proper subset of `K`. Thus (3e) also strictly
reduces the named packet without requiring a strict-root sacrifice.

Under that additional priority premise, a recurrent multi-good packet would satisfy

\[
 v_r(g)>\delta\qquad(g\in K,\ |K|\ge2).          \tag{3f}
\]

In the generic current state, however, another fixed-priority nonroot owner
may already lie below her base coordinate. Root equality plus a gain for `u`
therefore need not be lexicographically above the globally maximal base.
Without a proved prefix-payment premise, (3e) does not close and (3f) is not
an unconditional conclusion.

## Exact subpacket cut

Let `mathfrak R^common` be any nonempty family of `K`-free exterior modes
compatible with every singleton return, and put

\[
 M_r=\max_{R\in\mathfrak R^{common}}v_r(R).       \tag{4}
\]

If no controlled singleton return is strict, then for every `g in K`,

\[
 v_r(g)\ge\delta+M_r.                            \tag{5}
\]

More generally, for each nonempty `T subseteq K`, its own complete compatible
mode family obeys

\[
 \max_R v_r(R)\le v_r(T)-\delta.                \tag{6}
\]

Equation (5) is the **atomwise exterior-pool dominance charge**. Summing it
and using `v_r(K)<=v_r(Z_r)=x+delta` gives

\[
 (|K|-1)\delta+|K|M_r\le x.                     \tag{7}
\]

The inequality is strict when `H` is nonempty. Every surviving retired atom
is therefore root-surplus critical and
dominates the root value of the best exterior pool simultaneously compatible
with all singleton returns.

## Equality boundary

When `v_r(R)=v_r(T)-delta` with nonempty `R`, the root returns exactly to
base. For proper `T`, the packet is physically split, but donor losses can
precede the return owner's gain in the fixed priority. Such donor-losing
equality therefore remains a typed priority/release face. The donor-free
case (3e) also remains open unless the complete earlier fixed-priority prefix
is paid.

## Claim boundary

The clean controlled-release theorem tests every strict retired subpacket,
proves proper-target separation, and derives the weak cuts (5)--(7). It does
not close equality, contradict atomwise pool dominance, close
the equality-priority face, show that a common exterior mode has a useful
positive lower bound from GG alone, normalize every other retired packet,
close `T_{L,times}^*`, or prove four-agent/general EFX.
