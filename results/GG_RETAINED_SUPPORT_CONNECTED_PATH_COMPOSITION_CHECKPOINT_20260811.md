## Cap-free composition chain

The following alternatives are exhaustive.

### 1. Minimal evolved-target source

Globally minimize a desired subset of `W`.  The resulting core is
common-safe.

- Source `q` closes with the root edge as a release-compatible PI component.
- Source `c` or `s` enters the finite external return/owner-growth component
  and its minimal Hall boundary.
- Source `r` enters the canonical two-stage root selector.

Thus an unsafe target is not a separate branch.

### 2. Canonical root response

At fixed `L`, first minimize the root core's `q`-value, maximizing anchor-
return payment over every common-safe root response.  If every return fails,
maximize the value of the floater-substituted root target.  If that also
fails, one canonical response `A=K+J` exposes a nonempty physical packet

\[
 K\subseteq B_q
\]

with the joint strict certificate

\[
 \begin{aligned}
 v_q(K)&>v_q(L\setminus J)+v_q(f),\\
 v_r(K)&>v_r(f)+v_r(A)-v_r(X_r).
 \end{aligned}                                      \tag{1}
\]

Changing common-safe root response cores at the same retained state cannot
avoid (1).

### 3. Global bilateral selector

Maximize `q(G)` over every root packet satisfying `v_r(G)<v_r(K)`.  Either
the bilateral exchange of `G` and `K` pays both mutual owners, or every
root-improving bilateral packet has the same strict order in both rows:

\[
 v_r(G)<v_r(K)\Longrightarrow v_q(G)<v_q(K).        \tag{2}
\]

Thus the later-owner sacrifice in the next operation is necessary across
the entire packet family, not an artifact of a local choice.

### 4. Complete connected transfer path

For any root-affordable `G`, including `G=empty`, allocate

\[
 Y_q=(X_q\setminus K)+f,
 \qquad Y_r=(X_r\setminus G)+K,
\]

and, when `G` is nonempty, give it to either external sink.  This is the
complete connected path

\[
 \mathrm{charity}\to q\to r\;(\to a).
\]

The root strictly improves, `q` loses only `K-f`, and an EFX endpoint is a
strict global lexicographic improvement.  Every non-EFX target has an exact
packet-replacement or target-threshold polarity, and the path's response
incoming packets are internally supplied.

The path is a sufficient geometry, not an exhaustive one.  The exact hard
profile also requires a four-owner fork.  The surplus-budgeted connected-
component lemma now permits any connected supplier graph and allows an
observer's realized gain to pay for a changed target's threshold overshoot.
Thus later recurrence closure may branch and need not preserve every old
common-safety threshold separately.

### 5. Permanent root response anchor

The completed `q` target contains the original common-safe desired root core

\[
 T_q+f.
\]

As an edge into slot `q`, it releases all of `B_q`, including `K`, and
therefore supplies every response into the changed root target.  A `q`
source for that root target closes a PI 2-cycle.  An external source grows a
root-anchored matching.  The only source collision is the explicit pair

\[
 \{Y_q,Y_r\}\longleftarrow\{r\}.                   \tag{3}
\]

## Exact remaining terminal

The chain above removes the former unnamed branches: q-margin reset,
switching among root responses, unsafe evolved targets, absence of a
nonempty compensation packet, fixed bilateral choice, and disconnected
release support.

The root-monopoly pair (3) is no longer a terminal: its unique root response
captures a nonempty `B_q` packet and enters the same complete charity path.
Top-only resets preserve, strictly enlarge, or capture the retained support,
and a floater-consuming reset is routed by its source.

The sole remaining terminal is the **source-margin/root-critical handoff
after a fixed-`U` split-core root flip**.  The permanent-anchor activity dichotomy shows
that every response-active `q` can be represented by an anchor-constrained
maximum matching, even when the anchor costs unrestricted rank.  Therefore
`q` is sacrificed only when she has no response edge to any active target.
The fixed-`U` global q-residual selector then eliminates every nonroot
source-inactive wall: successful repair and nonroot J-exhaustion both
strictly raise the same q-row residual across all response ranks.  The known
desired mutual core `D(U)=(T_r\setminus U)+f` remains available even when its
goods are split across several targets.  Reassembling this split-support
response and applying universal reset gives protected `q` coverage, strict
growth of `U`, captured-margin rotation, or an explicit `q`- or external-
source margin packet.  The root-budget frontier then maximizes that source's
final utility over every root-paid split and replacement inside the complete
two-row pool.  It either restores the source or produces an exchange-stable
cut: every boundary good exceeds the root slack and every root-affordable
swap has the opposite source order.  Since all two-row packet choices have
already been optimized, a proof must now enlist a third owner in a surplus-
budgeted connected fork; unsafe/hitting-set augmentation remains the other
route.

Full-priority anchor selection prevents that augmentation from opening a new
matching-label cycle.  Among anchor-constrained maximum matchings, protect
the complete nonroot source-priority vector.  Every unmatched source then
points only to the root anchor or to an earlier protected source, so its
blocker chain is strictly priority-decreasing.  Simultaneous retained-core
reset preserves the protected prefix, grows `U`, or captures the `q` margin.
The third-owner gate is consequently physical rather than graph-theoretic:
close the terminal root-facing/J-exhausted handoff or unsafe-overlap cut with
one connected fork.

The fixed-`U` residual selector now applies to any distinguished nonroot
hole, not only `q`.  It ranges over every root-anchored response rank and
maximizes the hole's residual in that owner's own valuation row.  Whole-core
descent, successful nonroot repair, and nonroot J-exhaustion all strictly
increase that same quantity.  Thus neither an active nor a response-silent
external source can circulate through the other nonroot cores: both are
forced to unsafe augmentation, EFX/PI, or the root-facing handoff.

At that handoff, residual maximality also rigidifies the root-preserving
partition.  The old root-core/residual split is feasible; every distinct
common-safe selected split would strictly improve the same hole residual and
is impossible.  An unsafe root target augments immediately.  The remaining
original split has an item-critical least good, and the finite compensator
frontier ends in exactly a top packet or the `f`-only captured-bottom packet.

The required third-owner fork now has a necessary-and-sufficient weak-payment
packet selector.  Return the captured packet to its source, replace its root value
with `K` from a protected donor core, and compensate that donor with `G` from
the root pool.  The fork succeeds exactly when the root replacement gap is

longer schematic: either the donor's entire core cannot replace the root
