# Anchor-target nonoverlap growth or nested-edge lemma

**Date:** 2026-08-13

**Status:** cap-free elimination of the q-target overlap inequality as an
independent terminal; only an exact nested root-facing response can recur

## Setting

At one reconstructed paid state let the permanent old root anchor be

\[
 K_r\subseteq Y_q,                                 \tag{1}
\]

where `K_r` is base-common-safe and strictly desired by `r` over `X_r`.
Let another source `b!=r` have a globally minimal current response

\[
 E\subseteq Y_q,
 \qquad v_b(E)>v_b(Y_b).                           \tag{2}

Write

\[
 J=E\cap K_r,
 \qquad S=E\setminus K_r.                         \tag{3}

Thus `S subseteq R_q=Y_q-K_r` and is physically disjoint from the exact
anchor.

## Nonanchor support branch

Let `K_b` be source `b`'s selected core in the mixed Hamiltonian matching.
Keep the root on `K_r` and give

\[
 Z_b=K_b+S.                                       \tag{4}

All other selected source cores remain unchanged. The bundles are pairwise
disjoint: `K_b` lies in a target distinct from `Y_q`, `S subseteq R_q`, and
`S` is disjoint from `K_r`.

Source `b` remains strictly above base even if deleting the overlap destroys
current desire, because positivity gives

\[
 v_b(K_b+S)\ge v_b(K_b)>v_b(X_b),                 \tag{5}

with strict growth over the selected core whenever `S` is nonempty. The
permanent anchor is unchanged. If (4), together with the other paid cores,
is EFX, it is a lexicographic improvement. If an enlarged target is unsafe,
global minimal extraction produces a new current/base response with its
complete target and signed label.

At a fixed exact response state, retain `S` in the source-support record.
Every nonempty fresh `S` strictly enlarges that finite physical support.
Universal retained-support reset either preserves it, enlarges it further,
or exposes the already named captured-margin packet. Hence a recurrent
anchor-target response cannot keep a nonempty unrecorded `S`.

## Nested branch

At exact recurrence the only remaining case is

\[
 S=empty,
 \qquad E\subseteq K_r.                           \tag{6}

Base common safety is downward closed, so (1) and (6) imply

\[
 \tau_h(E)\le v_h(X_h)\qquad(h\in N).             \tag{7}

Together with (2) and `Y_b>=X_b`, this makes `E` an old/base-common-safe
desired core for source `b`. Thus the alleged decorated anchor collision has
converted into a second old response edge `b -> q` nested in the permanent
anchor target.

If this complete source/core/target label is new, it is finite response
augmentation. If it is old, the anchor-constrained full-priority matching
selector classifies it as an explicit root-facing blocker edge. It must
enter the root-budget/third-owner handoff; it is no longer a signed-surplus
or q-residual payment inequality.

## Consequence

All twelve anchor-target response orders—six forward and six backward—have
one of four outcomes:

1. EFX lexicographic improvement;
2. unsafe enlarged-target response augmentation;
3. strict retained q-residual support growth; or
4. an exact nested base-common-safe root-facing edge.

Therefore the q-target overlap itself is not a terminal root/q reverse
inequality. The remaining anchor-specific scalar gate is root-sourced
compensation while retaining `K_r`, but its physical selector must use the
complete signed residual pool, not only `R_q`.

## Claim boundary

This lemma proves physical disjointness, payment, support growth, hereditary
base safety, and the nested-edge conversion. It does not terminate the old
root-facing handoff, eliminate root-sourced complete-pool capture, force the
one/two decorated-head exchange, close GG, or prove four-agent/general
additive EFX.
