## Complete-exterior return candidate

include goods from `Z_u`: a strict root permits the later return owner to be

\[

 \qquad Z'_u=(Z_u\setminus R_u)+K,               \tag{4}

The return owner may gain or lose; no payment is assumed in the strict-root

\[
 v_r(H+R)-x=\delta-v_r(K)+v_r(R).                \tag{5}

\[
 v_r(R)>v_r(K)-\delta.                           \tag{6}
\]

If `v_r(K)<delta`, the empty packet already satisfies (6).
