# Partial-EFX Pareto Completion Gate

**Status:** exact counterexample; selector retired  
**Scope:** eligible one-floater EFX states for four positive-additive agents  
**Not affected:** the maximum-Nash completion conjecture and complete additive
EFX existence

## Refuted statement

For a valuation profile (V), let \(\mathcal E(V)\) contain the partial EFX
allocations \((X,f)\) with one unallocated good (f) and

\[
v_i(X_i)\ge v_i(f)\qquad\text{for every agent }i.
\]

The proposed shortcut was:

> Every Pareto-maximal utility vector realized in \(\mathcal E(V)\) has an
> insertable realization.

Here insertable means that the floater can be added to some bundle without
breaking EFX. The statement would have implied the four-agent complete-EFX
theorem using the published almost-complete starting allocation. It is false.

## Exact refutation

The fixed (4\times9) profile is

\[
\begin{pmatrix}
1&2&4&8&16&32&6208&4224&256\\
16385&3538&25140&4104&16&34848&31808&128&2304\\
10241&2&18436&8200&20496&32&29760&128&6400\\
1&5&1&8&18835&20512&19520&128&3965
\end{pmatrix}.
\]

Exact enumeration finds 323 eligible states, 322 distinct own-utility
vectors, and 43 Pareto-frontier vectors. The vector

\[
(10432,32782,30737,20512)
\]

is Pareto maximal. It has exactly one realization: good 8 floats and the
owner vector is

\[
(2,1,1,1,2,3,0,0,-).
\]

All four insertions fail, so no realization of this frontier vector is
insertable. This is a literal counterexample to the selector, not a search
timeout or numerical boundary.

## Why maximum Nash survives

The blocked vector has utility product

\[
215611792091795456.
\]

Nine frontier vectors have larger product. The unique maximum-product vector
is

\[
(4224,45629,29760,43312),
\]

with product (248431136281067520); its realization accepts the floater at
hosts 0 and 3. Across the 155-profile stored corpus scan, seven profiles have
a blocked Pareto-frontier vector, but every one of their maximum-product
vectors is insertable.

This exposes the exact distinction. Pareto maximality only excludes a state
that weakly improves all four utilities. It cannot compare frontier states
that help some agents and hurt others. Nash product supplies that missing
global comparison.

## Local isolation versus global rescue

The refuting state has only one eligible floater-exchange neighbor. That
neighbor changes the floater from good 8 to good 7, is insertable at hosts 1
and 2, and lowers the product to (133599944793075712). Reversing the
exchange is its only eligible continuation, so this local exchange component
has exactly two states.

There are nevertheless 24 insertable eligible states with product larger
than the blocked vector. Every such state changes at least four entries of
the good-owner vector. Thus a monotone one-floater exchange path cannot
explain the rescue. The surviving proof target must extract a genuinely
global rematching from maximum-Nash optimality.

## Claim boundary and next gate

This result refutes only the Pareto-maximal selector. It is not an additive
EFX counterexample: the profile has many insertable partial states and hence
complete EFX allocations. It also does not refute maximum-Nash completion.

The next analytic gate is therefore unchanged but sharper: assume an
eligible maximum-product state is blocked, use its unenvied source host and
floater-support inequalities, and derive a globally rematched eligible rival
with larger product or an equal-product insertable realization. Pure Pareto
dominance, a single floater exchange, and the complete 192-member local
source-substitution family are all insufficient universal mechanisms.
